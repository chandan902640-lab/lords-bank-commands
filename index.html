Guild Bank Commands

Important Tips

  • If a player's name has spaces, use quotes or underscore (e.g. !setacc "Player 1" or !setacc Player_1).
  • Authorized users and R4+ have administrator balance privileges by default.
  • The bank bot will not reply during long tasks like hero stages.

General Commands

Command Function Example Result
!payransom Pays outstanding Ransom for accounts leader !payransom Ransom is paid
!clearboard Clears all quests from Guild Fest board !clearboard Quests deleted
!shield [deploy] Checks shield time or deploys a shield !shield deploy Shield activated
!relocate [X] [Y] Relocates the bank to target coordinates !relocate 243 209 Bank relocates
!hunt [x] [y] Hunts specified monster on coordinates !hunt 150 166 Hunts monster
!purge Clears the Guild Chat !purge Chat cleared

Search Commands

Command Function Example Result
!findtile [type] [lvl] Finds resource tiles around the bank !findtile food 4 Sends result via mail
!findmonster [name] [lvl] Finds monster around castle bank !findmonster hardrox 2 Sends result via mail
!findnest [level] Finds darknest around the bank !findnest 3 Sends darknest mail

Balance & Resources

Command Function Example Result
!bal Checks your current sent balance !bal Sends balance status
![type] [amount] Sends specific resource !food 5M Bank sends 5M Food
!rss [F] [S] [W] [O] [G] Sends all types of resources !rss 5M 5M 5M 5M 0 Bank sends RSS bundle
!setacc [player] Credits balance to another account !setacc Shark Balance credited to Shark
